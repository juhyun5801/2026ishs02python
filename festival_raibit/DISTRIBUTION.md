# raibitScoreboard 2.1.16 사용 안내

근전도 센서로 5초 동안 측정하는 1인 점수 게임입니다. Python이나 Node.js를 따로 설치하지 않아도 됩니다. 설치 후 게임·소리는 인터넷 없이 동작합니다.

## 내 컴퓨터에 맞는 파일

| 컴퓨터 | 파일 | 실행 순서 |
|---|---|---|
| Windows 10/11, 64비트 PC | `raibitScoreboard-Windows-2.1.16.exe` | 내려받아 더블클릭. 설치 없이 실행합니다. |
| Windows에 설치해서 사용 | `raibitScoreboard-Windows-Setup-2.1.16.exe` | 설치 안내를 따라 설치 후 실행합니다. |
| Apple Silicon Mac: M1/M2/M3/M4/M5 등 | `raibitScoreboard-Mac-AppleSilicon-2.1.16.dmg` | DMG를 열고 앱을 Applications로 끌어 놓은 뒤 응용 프로그램에서 실행합니다. |
| Intel Mac | `raibitScoreboard-Mac-Intel-2.1.16.dmg` | DMG를 열고 앱을 Applications로 끌어 놓은 뒤 응용 프로그램에서 실행합니다. |

Mac은 macOS 11 이상이 필요합니다. 왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 칩이 Apple M 계열인지 Intel인지 확인합니다. Windows ARM/32비트와 macOS 10.15 이하는 별도 지원 대상이 아닙니다.

통합 ZIP을 받았다면 먼저 압축을 풀고 해당 컴퓨터에 맞는 파일 하나를 사용하세요. Mac 앱은 DMG 안에서 꺼내 설치하므로 Windows에서 DMG를 열거나 앱을 다시 압축할 필요가 없습니다.

## 처음 열 때 확인

Windows 개발자 인증서와 Apple Developer 공증은 포함하지 않았습니다. Mac 앱은 로컬 무계정 서명으로 무결성을 확인했습니다.

Mac에서 개발자를 확인할 수 없다는 안내가 나오면 앱을 한 번 열어 본 뒤, 시스템 설정 → 개인정보 보호 및 보안에 표시되는 해당 앱의 실행 확인 항목을 확인하세요. 신뢰하는 배포본인지 확인한 후 ‘확인 없이 열기’를 선택하고 다시 실행할 수 있습니다. 시스템 전체 보안을 끄거나 터미널 명령을 실행할 필요는 없습니다.

Apple 공식 안내: https://support.apple.com/102445

## 센서 연결과 게임 시작

1. SpikerBox와 근전도 센서를 연결하고 SpikerBox를 USB로 컴퓨터에 연결합니다. Spike Recorder 등 같은 장치를 사용하는 프로그램은 닫습니다.
2. 외부 시작용 아두이노도 사용한다면 USB로 연결합니다. 아두이노는 기존처럼 `START` 줄과 연결 확인용 `ALIVE` 줄을 보냅니다. 새 기기에서도 기존 아두이노 스케치를 그대로 사용합니다.
3. Windows는 Ctrl+D, Mac은 Control+D로 관리자 화면을 엽니다. ‘시뮬레이션’은 끈 상태로 사용합니다.
4. 다른 장소·센서에서는 팔을 편하게 두고 ‘영점 잡기’ 또는 3페이지 ‘잡음만’ 보정을 합니다. 자동 보정 전체 실행 시 기준 힘까지 바꾸는 항목을 선택하면 현재 기준 힘 35가 달라질 수 있습니다.
5. ‘이름 받고 시작’이 켜져 있으면 시작 신호 뒤 이름을 입력하고 Enter를 누릅니다. 관리자 화면의 ‘측정 시작’으로도 시작할 수 있습니다.
6. 5초 동안 측정하며 가장 높은 점수를 결과로 저장합니다. 측정 중 기계음이 높아지고, 결과가 나오면 팡파르가 한 번 납니다.

## 확정한 점수·소리 설정

- 기준 힘: 35 / 기준 힘 100%의 점수: 3000 / 곡선: 보통 0.6.
- 기준 힘의 절반이면 약 1979점입니다. 3000은 최대 점수가 아니라 기준 힘의 점수이며, 더 강한 신호는 더 높은 점수가 됩니다. 점수 상한은 9999입니다.
- 효과음 켜짐 / 음량 34%. 3페이지 오른쪽 맨 위에서 변경할 수 있습니다. 컴퓨터 스피커·출력 장치·음소거 상태도 확인하세요.
- 새 기기에는 이 값이 처음부터 적용됩니다. 기존 버전의 설정이 남아 있다면 3페이지 → 설정 파일 → 가져오기에서 `raibit-final-settings-2.1.16.json`을 선택합니다. 가져올 때 현재 기기의 영점은 유지됩니다.
- F11로 전체화면을 전환합니다. Mac의 관리자 단축키는 Command+D가 아닌 Control+D입니다.

## 파일을 다른 사람에게 보낼 때

`raibitScoreboard-AllPlatforms-2.1.16.zip` 하나를 그대로 보내면 Windows와 Mac용 파일 및 이 안내가 함께 전달됩니다. GitHub Releases 다운로드 링크도 그대로 공유할 수 있습니다.

개인 기록·이름·녹화 파일은 이 묶음에 들어 있지 않습니다. 새 기기의 기록은 빈 상태로 시작하고, 점수와 기기별 보정은 해당 컴퓨터에 저장됩니다.

검증: 게임·필터·점수·소리 자동 테스트, Windows 포터블 실행, Mac 두 종류 실제 macOS 빌드·앱 실행·서명 확인. 실제 센서·외부 아두이노 동작은 각 현장 장비에서 확인하세요.
